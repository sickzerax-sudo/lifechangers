LIFECHANGERS — COMO ABRIR

IMPORTANTE: para instalar como PWA, o app precisa ser servido por localhost ou hospedado em HTTPS. Não basta abrir o index.html com duplo clique.

OPÇÃO MAIS SIMPLES (Windows):
1. Instale o Visual Studio Code e a extensão "Live Server".
2. Extraia a pasta LifeChangers.
3. Abra a pasta no VS Code.
4. Clique com o botão direito em index.html e escolha "Open with Live Server".
5. O app abrirá no navegador. O endereço normalmente começa com http://127.0.0.1:5500.
6. No Chrome, use o ícone de instalação na barra de endereço ou o menu ⋮ > Salvar e compartilhar > Instalar página como app (o texto pode variar).

SEM VS CODE:
1. Instale Python 3, se ainda não tiver.
2. Abra o Prompt de Comando dentro da pasta LifeChangers.
3. Execute: python -m http.server 8000
4. Abra http://localhost:8000 no Chrome.

NO CELULAR:
Para instalar no celular, publique a pasta em um serviço de hospedagem HTTPS (por exemplo, GitHub Pages ou Netlify) e abra o link no navegador do celular. Para testar localmente, PC e celular precisam estar na mesma rede e o servidor deve aceitar conexões da rede.

O QUE JÁ FUNCIONA:
- Missões diárias e personalizadas
- XP, níveis e moedas
- Oito atributos, incluindo Autocuidado & Estilo
- Conquistas
- Recompensas pessoais
- Salvamento local no navegador (localStorage)
- Layout adaptável a PC e celular
- Cache básico para uso offline após a primeira visita

LIMITAÇÕES DESTA VERSÃO:
- O salvamento fica neste navegador/dispositivo; não sincroniza automaticamente entre PC e celular.
- A lista de missões reinicia diariamente; o XP total permanece.
- Esta é uma primeira versão local, sem conta/login ou nuvem.
- Use o app como apoio à rotina, sem transformar metas em cobrança. Ajuste ou pule missões quando precisar.
