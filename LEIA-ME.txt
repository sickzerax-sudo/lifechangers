LifeChangers 3.3 — Mobile e balanceamento

1. No aplicativo atual, exporte um backup antes de atualizar.
2. Extraia este ZIP e envie TODOS os arquivos para a raiz do mesmo repositorio GitHub Pages.
3. Substitua os arquivos antigos, faca commit e atualize o site.
4. Nao apague os dados do site nem o armazenamento local do navegador.

Novidades: fontes e botoes maiores no celular; layout adaptado; zoom de pinça desabilitado nos navegadores que respeitam essa configuracao; recompensas padrao mais acessiveis (45 a 350 moedas); recompensa personalizada a partir de 30 moedas; progressao de nivel media e crescente, preservando XP acumulado.

Observacao: desabilitar zoom pode afetar acessibilidade. Alguns navegadores podem permitir zoom por configuracoes de acessibilidade.
